1

무엇을 만드나요

주제 하나를 정해 유튜브 영상을 모아 놓은 나만의 아카이브 사이트입니다.

유튜브에는 좋은 영상이 많지만, 필요할 때 찾기가 어렵습니다. 검색하면 광고와 자극적인 썸네일이 먼저 나오고, 어제 봐 둔 영상은 다시 못 찾죠. 그래서 내가 직접 고른 영상만 모아 둔 사이트를 만듭니다.

만들고 나면 이렇게 쓸 수 있어요. 주제별로 분류돼 있고, 재생시간·학년으로 걸러 볼 수 있고, 링크 하나만 알면 누구나 씁니다. 회원가입도 앱 설치도 없습니다.

🎯

주제를 하나로

교육영상, 요리 레시피, 운동 루틴, 악기 강좌… 범위가 좁을수록 좋은 아카이브가 나와요.

🗂️

분류를 미리

20~35개 정도가 적당해요. 너무 적으면 못 찾고, 너무 많으면 어디 있는지 헷갈립니다.

💸

돈이 안 듭니다

유튜브 API도, 저장소도, 배포도 전부 무료 범위 안에서 끝나요.

🤖

코드는 AI가

여러분은 "무엇을 모을지" 정하고, 코드는 클로드·ChatGPT에게 맡깁니다.

ℹ️
왜 API가 필요한가요

유튜브 화면을 손으로 긁어 오는 건 규칙 위반이기도 하고, 무엇보다 영상이 삭제됐는지 알 수가 없어요. API를 쓰면 제목·재생시간·공개 여부를 정확히 받아올 수 있고, 나중에 "이 영상 아직 살아 있나?"를 자동으로 확인할 수 있습니다.

💡
이 순서대로, 쉬운 것부터

API 키 → 할당량 이해 → 수집 → 선별 → 화면 → 배포. 특히 3단계(할당량)를 건너뛰면 첫날 오후에 막힙니다. 그리고 AI에게 주는 프롬프트는 전부 「쉬운 버전」과 「자세한 버전」 두 가지로 넣어 뒀어요. 처음엔 쉬운 것만 쓰시고, 아쉬울 때 자세한 걸 꺼내 쓰세요.

2

API 키 발급받기

구글 계정만 있으면 10분이면 끝나요. 카드 등록도 필요 없습니다.

🛠️따라 하기

구글 클라우드 콘솔 접속

console.cloud.google.com 에 구글 계정으로 로그인해요. 처음이면 약관 동의 화면이 한 번 나옵니다.

프로젝트 만들기

왼쪽 위 프로젝트 선택 → 새 프로젝트. 이름은 아무거나(예: my-archive) 넣고 만들면 돼요.

YouTube Data API v3 사용 설정

검색창에 YouTube Data API v3 를 치고 들어가 사용 버튼을 누릅니다. 이걸 안 하면 키를 만들어도 작동하지 않아요.

API 키 만들기

왼쪽 메뉴 API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → API 키. AIza... 로 시작하는 문자열이 나옵니다. 이게 열쇠예요.

키 제한 걸기 (권장)

만들어진 키를 눌러 API 제한사항에서 YouTube Data API v3 만 선택해 두세요. 키가 새어 나가도 피해를 줄일 수 있어요.

🔐
키는 절대 공개하지 마세요

API 키를 웹사이트 코드 안에 넣으면 안 됩니다. 누구나 소스 보기로 꺼내 쓸 수 있고, 남이 쓴 할당량도 내 몫에서 빠져나가요. 키는 내 컴퓨터에서 영상을 모을 때만 쓰고, 배포할 사이트에는 결과 파일(JSON)만 올립니다.

⚠️
깃허브에 실수로 올리면

공개 저장소에 키가 올라가면 몇 분 안에 자동으로 탐지돼 구글이 키를 정지시킵니다. 그럴 땐 콘솔에서 기존 키를 삭제하고 새로 만드세요. 되살리려 하지 말고요.

3

할당량 먼저 이해하기

이걸 모르면 첫날 오후에 "갑자기 안 돼요" 를 겪습니다.

유튜브 API는 하루에 쓸 수 있는 양이 정해져 있어요. 기본은 하루 10,000 단위(unit) 입니다. 그런데 기능마다 소모량이 완전히 다릅니다. 이게 핵심이에요.

하는 일1회 비용기능 이름
검색어로 영상 찾기100 단위search.list
영상 정보 보기 (제목·길이·공개 여부)1 단위videos.list
재생목록 안의 영상 목록 보기1 단위playlistItems.list
채널 정보 보기1 단위channels.list

오른쪽 기능 이름은 외우지 않아도 됩니다. 다만 AI가 준 코드에서 이 단어를 보게 되고, 오류 메시지에도 나오니 "아, 이게 검색이구나" 정도만 알아 두면 나중에 문제가 생겼을 때 훨씬 수월해요.

검색만 100배 비쌉니다. 하루 10,000이면 검색은 100번밖에 못 해요. 반면 상세조회는 10,000번 가능하죠. 그래서 이렇게 설계합니다.

💡
검색은 아껴 쓰고, 정보 조회는 마음껏

검색 한 번에 최대 50개까지 받을 수 있어요. 그러니 검색으로는 영상 번호만 긁어모으고, 그 번호들을 50개씩 묶어서 정보를 받아 오면 됩니다. 이러면 500편을 확인하는 데 10단위밖에 안 들어요. AI에게 "검색은 최소한으로 하고 정보는 몰아서 가져와 줘" 라고만 해도 이렇게 짜 줍니다.

ℹ️
검색을 아예 안 쓰는 방법도 있어요

모으고 싶은 채널이 정해져 있다면 검색이 필요 없습니다. 채널 ID가 UC 로 시작하는데, 앞 두 글자를 UU 로 바꾸면 그 채널의 "전체 업로드 재생목록" ID가 돼요. 이걸 playlistItems.list 로 넘기면 1단위씩만 쓰면서 채널 영상을 전부 훑을 수 있습니다. 저는 검색 할당량이 떨어진 날 이 방법으로 300편 가까이 모았어요.

⚠️
할당량은 태평양 시간 자정에 초기화

한국 시간으로 대략 오후 4~5시입니다. "오늘 다 썼다" 싶으면 그때까지 기다리거나, 위의 재생목록 방식으로 넘어가세요. 참고로 검색 할당량과 조회 할당량은 따로 셉니다 — 검색이 막혀도 조회는 계속 돼요.

4

AI에게 수집 시키기

코드를 직접 쓰지 않습니다. 아래 프롬프트를 그대로 복사해 쓰세요.

클로드나 ChatGPT에게 말로 부탁하면 됩니다. 처음부터 어렵게 쓸 필요 없어요. 이 정도면 충분히 돌아가는 코드가 나옵니다.

① 먼저 이렇게 — 쉬운 버전
유튜브에서 영상을 모으는 프로그램을 만들어 줘.

내가 하고 싶은 것:
- 유튜브 API 키는 있어. (없으면 발급받는 법도 알려 줘)
- "초등학생 안전교육" 같은 검색어로 영상을 찾고 싶어
- 찾은 영상의 제목, 채널 이름, 길이를 파일로 저장하고 싶어

나는 코딩을 잘 몰라. 컴퓨터는 윈도우야.
파일을 어디에 저장하고 어떻게 실행하는지도 알려 줘.

돌려 보면 결과가 나옵니다. 그런데 몇 번 써 보면 아쉬운 게 생겨요. 광고가 섞이고, 두 시간짜리 영상이 들어오고, 어제 본 영상이 또 나옵니다. 그때 아래를 주세요.

💡
전문 용어를 쓸 필요가 없어요

"이 함수를 이렇게 고쳐" 라고 말할 필요 없습니다. 겪은 불편을 그냥 말로 설명하면 돼요. "1분도 안 되는 광고가 자꾸 섞여" 라고 하면 AI가 알아서 걸러내는 코드를 씁니다. 용어를 아는 게 실력이 아니라, 무엇이 불편한지 정확히 말하는 게 실력이에요.

ℹ️
한꺼번에 다 주지 마세요

짧게 시작해 부족한 것만 덧붙이는 게 AI에게도 좋고, 무엇보다 여러분이 코드를 이해하기 좋아요. 처음부터 조건 열 개를 주면 뭐가 뭔지 모르는 코드가 나옵니다.

② 아쉬우면 이렇게 — 자세한 버전
아까 만든 영상 모으는 프로그램, 며칠 써 보니까 아쉬운 게 있어.
아래대로 고쳐 줘.

1. 검색을 많이 하면 하루 쓸 수 있는 양이 금방 떨어지더라.
   검색은 최대한 아껴 쓰고, 검색으로는 영상 번호만 받아온 다음에
   자세한 정보는 한 번에 여러 개씩 몰아서 가져오게 해 줘.
   그리고 오늘 검색을 몇 번 썼는지 화면에 찍어 주면 좋겠어.

2. 이런 게 자꾸 섞여 들어와. 빼 줘.
   - 비공개거나 없어진 영상
   - 1분도 안 되는 짧은 광고
   - 40분 넘는 긴 영상 (수업 시간에 못 틀어)
   - 뉴스 방송국이 올린 것 (YTN, KBS 뉴스, MBC 뉴스, SBS 뉴스 같은 데)
   - 제목에 이런 말이 들어간 것 — 홍보영상, 소개영상, 발대식,
     수료식, 기념식, 워크숍, 세미나, 인터뷰, 브이로그, 쇼츠
     교육 내용이 아니라 행사 기록이더라고

3. 저번에 모은 영상이 또 나와. 이미 모아 둔 목록이랑 비교해서
   새로 나온 것만 남겨 줘.

4. 결과 파일은 한 줄에 영상 하나씩, 영상 번호랑 제목이랑
   채널 이름이랑 몇 분짜리인지가 보이게 정리해 줘.
   주제별로 파일을 나눠 주면 더 좋고.

5. API 키를 코드 안에 적어 두면 위험하다던데,
   그건 밖에서 넣는 방식으로 바꿔 줘.

윈도우에서 어떻게 실행하는지도 다시 알려 줘.

AI가 코드를 주면 파일로 저장하고 실행하면 됩니다. 실행할 때 API 키를 앞에 붙여 넘겨요.

실행 (윈도우 PowerShell)
$env:YT_KEY="여기에_발급받은_키"
node collect.mjs
💡
검색어를 잘 짜는 게 절반입니다

같은 주제라도 안전교육 보다 초등학생 안전교육 애니메이션 처럼 대상 + 주제 + 형식을 넣으면 훨씬 정확해요. 카테고리마다 검색어를 3~5개씩 준비하세요.

후보가 수백 건 나오면 눈으로 보기 힘들어요. 그럴 땐 AI에게 "제목만 뽑아서 짧게 정리해 줘" 라고 다시 시키면 검토하기 편한 목록이 나옵니다. 저는 1,000건이 넘으면 항상 이렇게 줄여서 봐요.

5

영상 골라내기

사이트의 품질은 "무엇을 넣느냐"보다 "무엇을 버리느냐"로 결정됩니다.

기계가 걸러 준 후보를 그대로 다 넣으면 안 됩니다. 사람이 한 번은 봐야 해요. 다만 기준이 있으면 훨씬 빨라집니다. 제가 쓰는 기준을 그대로 알려드릴게요.

이런 건 버려요왜요
기관 소개·홍보영상"우리 센터를 소개합니다" 는 배울 게 없어요
행사 기록발대식·시상식·현장 스케치는 내용이 없습니다
뉴스 보도정보는 있지만 금방 낡고, 교육자료가 아니에요
대상이 다른 것제목에 "학부모용·교사용·성인" 이 있으면 뺍니다
1분 미만대부분 광고예요. 캠페인송처럼 쓸모 있는 건 예외
40분 초과수업 한 시간에 못 틀어요
기업 브랜드 채널가장 조심할 부분 — 아래 설명
⚠️
브랜드 채널을 조심하세요

교육 콘텐츠처럼 보이지만 사실은 광고인 영상이 아주 많아요. 학습지 회사, 금융사, 사교육 브랜드가 만든 것들이죠. 내용은 그럴듯한데 끝에 자사 홍보가 붙습니다. 저는 채널명 목록을 만들어 수집 단계에서 아예 차단했어요. 손으로 걸러내려면 매번 지칩니다.

💡
버린 것은 반드시 기록해 두세요

제거한 영상의 ID와 이유를 removed.json 같은 파일에 남기고, 다음 수집 때 이 목록을 제외하도록 하세요. 안 그러면 지웠던 영상이 다음 달에 또 후보로 올라옵니다. 저는 이걸 안 해서 같은 영상을 세 번 지웠어요.

ℹ️
중복은 생각보다 많습니다

같은 영상이 다른 검색어에서 또 잡히거나, 같은 자료를 여러 기관이 각자 올려 둔 경우가 흔해요. 제목이 조금씩 다르니 자동으로는 못 잡습니다. 제목에서 괄호·기호·숫자를 뺀 뒤 비교하면 꽤 걸러져요.

6

화면 만들기

HTML 파일 하나 + 데이터 파일 하나. 이게 전부입니다.

복잡한 도구는 필요 없어요. HTML 파일 한 개에 화면을, JSON 파일 한 개에 영상 목록을 넣습니다. 데이터를 나눠 두면 영상을 추가할 때 화면 코드를 안 건드려도 돼요.

데이터 파일(videos.json) 생김새
[
  {
    "id": "abc123XYZ99",
    "title": "초등 저학년 교통안전 교육",
    "cat": "안전교육",
    "lv": "elem",
    "dur": 8.5,
    "desc": "횡단보도 건너는 법을 배우는 애니메이션"
  }
]
① 먼저 이렇게 — 쉬운 버전
내가 모은 유튜브 영상 목록을 보여주는 웹페이지를 만들어 줘.

- videos.json 파일에 영상 목록이 들어 있어 (같은 폴더)
- 영상마다 썸네일이랑 제목이 보이면 좋겠어
- 누르면 유튜브로 넘어가게
- 주제별로 나눠서 볼 수 있으면 좋겠어
- 휴대폰에서도 잘 보이게

HTML 파일 하나로 만들어 줘. 복잡한 도구는 안 쓰고 싶어.

이 정도면 쓸 수 있는 화면이 나옵니다. 써 보다가 "검색이 있으면 좋겠다", "즐겨찾기가 필요하다" 싶을 때 하나씩 덧붙이면 돼요. 아래는 제가 실제로 쓰는 화면의 조건을 전부 적은 것입니다.

② 기능을 더 붙이려면 — 자세한 버전
아까 만든 영상 목록 페이지, 써 보니까 아쉬운 게 있어.
아래대로 고쳐 줘.

- 영상이 많아지니까 찾기가 힘들어. 검색창을 넣어 줘.
- 초등학생용인지 중학생용인지 골라서 볼 수 있으면 좋겠어.
- 시간 없을 때 짧은 것만 보고 싶어. 몇 분짜리인지로도 거를 수 있게.
- 마음에 든 영상은 표시해 뒀다가 나중에 다시 찾고 싶어.
- 최근에 본 영상도 남으면 좋겠고.
- 영상이 수천 개라 한 번에 다 띄우면 느려.
  처음엔 조금만 보여주고 아래로 내리면 더 나오게 해 줘.

그리고 이건 꼭 지켜 줘. 겪어 보고 아는 거야.

- 영상을 사이트 안에 심지 말고 유튜브로 넘겨 줘.
  안에 심으면 어떤 영상은 검은 화면만 나오더라.
- 아이콘을 인터넷에서 불러오지 말고 파일 안에 넣어 줘.
  학교 인터넷에서 막혀서 아이콘이 다 사라진 적이 있어.
- 총 몇 편인지는 내가 숫자를 적는 게 아니라
  목록 개수를 세서 자동으로 나오게 해 줘. 매번 고치기 귀찮아.
- 휴대폰에서도 잘 보이게. 화면이 좁으면 왼쪽 목록은
  버튼 눌렀을 때만 나오게 하면 될 것 같아.
🔐
재생 방식을 미리 정하세요

영상을 사이트 안에 심을지(iframe), 유튜브로 보낼지 정해야 해요. 심으면 보기 좋지만, 일부 영상은 "외부 사이트 재생 금지" 설정이 걸려 있어 검은 화면만 나옵니다. 유튜브로 보내면 그런 문제가 아예 없어요. 저는 후자를 택했고, 덕분에 재생 불가 영상이 0건입니다.

⚠️
외부 CDN을 조심하세요

아이콘이나 글꼴을 외부 주소에서 불러오면, 학교나 회사 네트워크에서 차단됐을 때 화면이 깨집니다. 저는 아이콘 라이브러리를 CDN으로 썼다가 학교망에서 아이콘이 전부 사라진 적이 있어요. SVG는 파일 안에 직접 넣으세요.

7

무료로 배포하기

깃허브 페이지스를 쓰면 서버 비용 없이 주소가 생깁니다.

🛠️따라 하기

깃허브 가입

github.com 에서 계정을 만들어요. 무료입니다.

저장소(repository) 만들기

오른쪽 위 + → New repository. 이름을 정하고 Public 으로 만듭니다. 비공개면 페이지스가 안 돼요(무료 요금제 기준).

파일 올리기

Add file → Upload files 로 index.html 과 videos.json 을 끌어다 놓고 Commit.

페이지스 켜기

Settings → Pages 에서 Source를 Deploy from a branch, 브랜치를 main(또는 master), 폴더를 / (root) 로 두고 저장해요.

1~2분 기다리기

사용자이름.github.io/저장소이름 으로 접속하면 사이트가 떠요. 바로 안 뜨면 조금 더 기다렸다 새로고침하세요.

💡
업데이트는 파일만 바꾸면 끝

영상을 추가했으면 videos.json 만 다시 올리면 됩니다. 몇 분 안에 반영돼요. 앱처럼 새로 설치할 필요가 없는 게 웹사이트의 장점이에요.

ℹ️
카카오톡 링크 미리보기를 예쁘게

HTML의 <head> 안에 og:title·og:description·og:image 를 넣으면 링크를 공유할 때 썸네일이 나와요. 이미지는 가로 1200px 정도가 적당합니다. 한 번 공유된 뒤에는 카카오가 결과를 저장해 두니, 바꿨는데 그대로면 카카오 디버거에서 초기화하면 됩니다.

망가지지 않게 관리

유튜브 영상은 예고 없이 사라집니다. 자동으로 확인하게 만들어 두세요.

아카이브의 가장 큰 적은 깨진 링크예요. 영상이 삭제되거나 비공개로 바뀌면 눌러도 안 나옵니다. 그런데 3천 편을 손으로 확인할 수는 없죠.

🔍

썸네일로 확인

삭제된 영상은 썸네일 주소가 아주 작은 기본 이미지를 돌려줘요. 크기가 2KB 미만이면 의심하면 됩니다. API 할당량을 안 씁니다.

📋

API로 정밀 확인

videos.list 로 status 를 받아 보면 삭제·비공개를 정확히 알 수 있어요. 3천 편에 60단위밖에 안 듭니다.

⏰

매달 자동 실행

깃허브 액션(Actions)으로 매달 1일에 자동 점검하게 해 두세요. 문제가 있으면 알림이 옵니다.

📝

점검 날짜 기록

카테고리별로 마지막 점검일을 적어 두면, 다음엔 오래된 것부터 보면 돼요.

① 먼저 이렇게 — 쉬운 버전
videos.json에 있는 유튜브 영상들이 아직 볼 수 있는 상태인지
확인하는 프로그램을 만들어 줘.

- 삭제되거나 비공개가 된 영상을 찾아서 알려 주면 돼
- 영상이 3천 개쯤 있어서 하나씩은 못 해

윈도우에서 어떻게 실행하는지도 알려 줘.

이걸로 깨진 영상을 찾을 수 있습니다. 다만 매번 손으로 돌려야 하죠. 자동으로 돌게 하고 싶으면 아래를 주세요.

② 자동으로 돌리려면 — 자세한 버전
아까 만든 점검 프로그램, 매번 내가 켜서 돌리기가 귀찮아.
알아서 돌아가게 해 줘.

- 한 달에 한 번, 1일에 저절로 돌면 좋겠어.
- 그래도 내가 확인하고 싶을 땐 직접 돌릴 수도 있게 해 주고.
- 깨진 영상이 나오면 그냥 지나가지 말고
  나한테 알림이 오게 해 줘. 어떤 영상이 깨졌는지 목록도 같이.

  여러 개를 동시에 확인하고, 얼마나 진행됐는지 보여 줘.

내 사이트는 깃허브에 올려 둔 상태야.
거기서 되는 방법으로 해 주고, 어디에 뭘 넣어야 하는지 알려 줘.

＋

자주 막히는 곳

제가 실제로 겪은 것들입니다. 미리 알면 안 겪어도 돼요.

  • "할당량 초과" 오류가 떠요 — 검색을 너무 많이 돌린 거예요. 한국 시간 오후 4~5시에 초기화됩니다. 급하면 채널 재생목록 방식(3단계 참고)으로 우회하세요.
  • 영상이 검은 화면으로 나와요 — 그 영상에 "외부 재생 금지" 가 걸린 겁니다. 사이트에 심지 말고 유튜브로 보내면 해결돼요.
  • 재생시간이 이상하게 나와요 — 유튜브는 PT1H2M3S 같은 형식으로 줍니다. 시·분·초를 각각 뽑아 계산해야 해요. 라이브 방송은 이 값이 비어 있으니 예외 처리도 필요합니다.
  • 같은 영상이 두 번 들어갔어요 — 검색어가 겹치면 흔합니다. 추가 전에 기존 ID 목록과 대조하는 코드를 꼭 넣으세요.
  • 편수 표시가 실제와 달라요 — 화면에 숫자를 직접 적어 두면 데이터를 고칠 때마다 어긋납니다. 데이터 개수에서 자동으로 계산하게 만드세요. 저도 이것 때문에 세 군데를 매번 고치다가 결국 자동화했어요.
  • AI가 준 코드가 안 돌아가요 — 오류 메시지를 그대로 복사해서 AI에게 다시 주세요. "안 돼요" 보다 훨씬 빨리 고쳐 줍니다.
  • 어디까지 모아야 할지 모르겠어요 — 한 카테고리에 30~50편이면 충분히 쓸 만합니다. 처음부터 완벽하게 채우려 하지 말고, 쓰면서 부족한 곳을 채워 가세요.
